# DSLX-life

8×8 Conway's Game of Life の DSLX データパスと、LED マトリクス向けの行スキャン出力です。

## 実装

[`life.dslx`](life.dslx) は盤面を `u64` のビットマップとして扱います。ビット `row * 8 + column` がセルの状態を表し、bit 0 は左上です。盤面の外側は死んだセルとして扱います。

- `next_generation(board)`: 各セルの8近傍を数え、誕生（近傍3セル）、維持（生存中かつ近傍2または3セル）、それ以外の死滅を適用します。
- `game_step(board, advance)`: `advance` が true のときだけ次世代を返します。FPGA では返り値を盤面レジスタの入力につなぎ、世代更新イネーブルのクロックエッジでレジスタを更新します。pause は `advance` を false にします。
- `display_scan(board, row)`: 指定行の列データと one-hot の行選択を返します。列出力 bit 7 が左端セルに対応し、セル点灯は high です。

## テスト

DSLX の `#[test]` でブロックの安定、ブリンカーの往復、孤立セルの消滅、pause、および表示行を確認します。XLS の DSLX テストランナーが必要です。

```sh
bazel run -c opt //xls/dslx:interpreter_main -- /absolute/path/to/life.dslx
```

このコマンドは XLS リポジトリのルートから実行します。単体の DSLX インタプリタを使う場合は、その `interpreter_main` にこのファイルのパスを渡してください。このリポジトリには XLS のテストランナー、特定 FPGA 向けのビルド設定、ボード制約ファイルは含まれていません。`next_generation` を組み合わせ回路として合成し、`game_step` の出力を盤面レジスタへ接続してください。

## FPGA / LED マトリクス接続

1. リセット時に盤面レジスタを初期パターン（例: `u64:0x000000001c000000` の横向きブリンカー）へ設定します。
2. 分周クロックまたはクロックイネーブルを使い、数百 ms ごとに `advance` を1クロックだけ有効にします。pause 中は無効にします。
3. 高速なスキャン用分周器で3ビットの `row` カウンターを0〜7で循環させ、`display_scan` の戻り値を行選択・列データへ接続します。表示には盤面レジスタの現在値を使います。
4. 行選択8本と列データ8本をマトリクスの対応する入力へ接続します。実際の極性、ピン番号、電流制限は FPGA ボードおよびマトリクスの仕様に合わせてください。必要なら外部ドライバを使用し、FPGA の GPIO に LED 電流を直接流しすぎないようにします。

世代更新回路は1回のイネーブル付きクロックで盤面レジスタへ反映できます。LED の行スキャンと世代更新は別のレートで動かしてください。具体的なトップレベル、クロック制約、ピン制約は対象ボードが決まった段階で追加します。
